# Угольный побег — v48

Статическая мини-игра для GitHub Pages. В v48 исправлено оформление обучения на ПК, возвращены звёздочки страниц и подключлены предоставленные WebP. Все девять новых файлов изображений сохранены без перекодирования.

## Обновление GitHub Pages

1. Распакуйте архив и откройте папку `Ugolny_Pobeg_v48`.
2. В репозитории нажмите **Add file → Upload files**.
3. Перетащите всё содержимое папки, **включая `assets` и `assets-loader.js`**. `index.html` должен остаться в корне репозитория.
4. Нажмите **Commit changes**. Настройки Pages менять не требуется: `main`, `/(root)`.
5. После окончания публикации перезагрузите игру. На ПК — `Ctrl+F5`, на телефоне — повторная загрузка страницы.

Сборка, npm и сервер приложения не нужны. Для локального просмотра можно открыть `index.html`.

## Оформление и загрузка

На большом экране восстановлена прежняя композиция: Лунна слева перед рамкой, текст справа. Для неё используются новый портрет `lunna.webp` и три предоставленные части подложки `dial1.webp`…`dial3.webp`. Части совмещаются при отображении без сохранения промежуточных пережатых картинок. Пропорции цельной рамки на ПК сохраняются.

На узком экране подложка меняет высоту вслед за текстом: середина продолжает края, углы сохраняют масштаб. Имя располагается отдельно; на вертикальном телефоне Лунна стоит справа. Мобильные правила отделены от композиции для ПК. Девять звёздочек отмечают страницы обучения; текущая звёздочка заполнена.

Лунна и все части оформления загружаются и декодируются до показа текста. При ошибке доступны повтор и пропуск. Пропуск не задерживает загрузку игровых изображений.

В верхней панели находятся «?», перезапуск, звук, полный экран и пауза. Отдельной полосы обучения нет. Внутри обучения также доступна кнопка полного экрана.

В полном экране игровое поле подстраивается под доступное окно. Если браузер не предоставляет нативный режим или блокировку ориентации, используется разворачивание и поворот интерфейса внутри страницы. Панели самого браузера могут оставаться видимыми.

## Управление

| Действие | Управление |
| --- | --- |
| Прыжок | Пробел, ↑, W или касание поля |
| Пауза / продолжение | P, Esc или кнопка паузы |
| Новый забег | R или ↻ |
| Звук | M или ♫ |
| Полный экран | F или ⛶ |
| Обучение | «?» в верхней панели |
| Следующая страница | Касание сцены, «Далее», →, пробел / Enter |
| Предыдущая страница | «Назад» или ← |
| Закрыть обучение | «Пропустить» или Esc |

Пробел на сфокусированной кнопке нажимает эту кнопку. Обводки фокуса отключены, клавиатурная навигация сохранена.

## Правила

Три огонька здоровья; столкновение отнимает один. Примогем добавляет 25 метров. Разгон учитывает активное время: ×2 на 3:00, ×5 на 10:00, ×13 на 30:00. Рекорд сохраняется в браузере. При повороте устройства, потере фокуса и изменении полноэкранного режима игра ставится на паузу.

## Проверка

`AUDIT.md` описывает изменения и границы проверки; `tests/validation-results.json` — результаты. Автономный тест физики: `node tests/game-regression.mjs` (Node.js 20+; для игры Node.js не требуется).

Основные файлы: `game.js` — игра и камера; `features.js` — диалоги и разворачивание; `assets-loader.js` — подготовка изображений и сборка подложки; `animation-config.js` — параметры анимации; `collision-masks.js` — маски столкновений; `style.css` — оформление.
