# Угольный побег — v47

Статическая мини-игра для GitHub Pages. В этой версии переработаны мобильные окна, загрузка обучения и разворачивание игрового поля. Тексты Лунны, скорость, прыжок, маски и расстояния между банками сохранены.

## Обновление GitHub Pages

1. Распакуйте архив и откройте папку `Ugolny_Pobeg_v47`.
2. В репозитории нажмите **Add file → Upload files**.
3. Перетащите всё содержимое этой папки, **включая папку `assets` и новый файл `assets-loader.js`**. `index.html` должен остаться в корне репозитория.
4. Нажмите **Commit changes**. Настройки Pages менять не требуется: `main`, `/(root)`.
5. После обновления публикации перезагрузите игру. На компьютере — `Ctrl+F5`, на телефоне — повторная загрузка страницы.

Для первого размещения используются те же файлы и настройки Pages. Сборка, npm и сервер приложения не нужны. Для локального просмотра можно открыть `index.html`.

## Что изменилось на телефоне

- Обучение сначала подготавливает Лунну и оформление и только затем показывает реплику. Если рисунок не загрузился, доступны повтор и пропуск.
- Загружается облегчённый портрет для мобильного экрана. Подготовленная рамка включена в стили, поэтому отдельный медленный запрос к ней не нужен.
- Начало, середина и конец предоставленной подложки собраны в гибкую рамку. Высота поля следует за текстом, углы и имя отделены от растягиваемой середины. Внутренней прокрутки текста больше нет.
- На вертикальном экране Лунна находится справа, имя — слева. В альбомном режиме сохранена композиция с Лунной слева от текста.
- На мобильном экране игровое поле занимает доступную высоту; крупная шапка страницы скрыта, чтобы не отнимать место.
- Если браузер не разрешает настоящий полный экран или поворот, игра разворачивается на видимое окно и поворачивает собственный интерфейс в альбомную ориентацию.
- Размер отрисовываемого мира подстраивается под окно. Фон заполняет поле с сохранением пропорций; на разных пропорциях окна он кадрируется. Котик и банки не растягиваются.
- Окна старта, паузы и результата используют читаемый текст и крупные кнопки. На невысоком экране сокращён декор, чтобы поместились текст и действия.

Панели самого браузера могут оставаться видимыми, когда браузер не предоставляет настоящий полноэкранный режим. Страница занимает доступную ей область; системный интерфейс браузера она не управляет.

## Управление

| Действие | Управление |
| --- | --- |
| Прыжок | Пробел, ↑, W или касание поля |
| Пауза / продолжение | P, Esc или кнопка паузы |
| Новый забег | R или ↻ |
| Звук | M или ♫ |
| Полный экран | F или ⛶ |
| Обучение | «?» в верхней панели |
| Следующая страница | Касание сцены, «Далее», →, пробел / Enter |
| Предыдущая страница | «Назад» или ← |
| Закрыть обучение | «Пропустить» или Esc |

В самом обучении появилась отдельная кнопка ⛶ в правом верхнем углу. Пробел на сфокусированной кнопке нажимает эту кнопку. Обводки фокуса отключены, клавиатурная навигация сохранена.

## Правила

Три огонька здоровья; столкновение отнимает один. Примогем добавляет 25 метров. Разгон учитывает активное время: ×2 на 3:00, ×5 на 10:00, ×13 на 30:00. Рекорд сохраняется в браузере. При повороте устройства, потере фокуса и изменении полноэкранного режима игра ставится на паузу.

## Проверка и файлы

`AUDIT.md` описывает изменения и границы проверки. `tests/validation-results.json` содержит сводные результаты. Автономный тест физики и длительного расчёта: `node tests/game-regression.mjs` (Node.js 20+; для самой игры Node.js не требуется).

Основные файлы: `game.js` — игра и камера; `features.js` — диалоги и разворачивание; `assets-loader.js` — подготовка изображений; `animation-config.js` — параметры анимации; `collision-masks.js` — неизменённые маски; `style.css` — оформление и встроенная рамка.
