# Угольный побег — v46

Готовая статическая мини-игра для GitHub Pages. Оформление, рисунки, текст обучения и баланс v43 сохранены. Исправлены ошибки интерфейса, полноэкранного режима, загрузки и подсчёта результата.

В v45 убраны обводки фокуса вокруг кнопок, игрового поля и сцены обучения при управлении с клавиатуры. Сами кнопки и клавиатурная навигация работают как прежде.

В v46 обучение перенесено под значок «?» рядом с перезапуском, звуком, полным экраном и паузой. Отдельная полоса обучения убрана из всех раскладок; в альбомном и полноэкранном режимах освобождённое место занимает игровое поле.

## Установка

1. Распакуйте архив.
2. Загрузите **содержимое** папки `Ugolny_Pobeg_v46` в корень репозитория GitHub Pages, заменив предыдущие файлы.
3. Откройте страницу. Если браузер показывает старую версию, обновите её с очисткой кэша: `Ctrl+F5`.

Сборка, npm, сервер приложения, аккаунты и внешние сервисы не нужны. Для локального запуска можно открыть `index.html`. Для проверки через HTTP из папки проекта выполните `python -m http.server 8000` и откройте `http://localhost:8000`.

## Управление

| Действие | Управление |
| --- | --- |
| Прыжок | Пробел, ↑, W или касание игрового поля |
| Пауза / продолжение | P, Esc или кнопка паузы |
| Новый забег | R или ↻ |
| Звук | M или ♫ |
| Полный экран | F или ⛶ |
| Обучение | Кнопка «?» в верхней панели, доступна и в полном экране |
| Страницы обучения | Касание рисунка, «Далее», «Назад», ← / →, пробел / Enter |
| Закрыть обучение | «Пропустить» или Esc |

Когда кнопка находится в фокусе, пробел нажимает именно её. В обучении клавиша Tab переключает его элементы управления. Длинный текст в маленьком окне можно прокрутить внутри поля диалога.

На телефоне при первом запуске вертикально появляется предложение повернуть экран; забег в этот момент стоит на паузе. Можно выбрать «Продолжить вертикально», затем продолжить игру. Поворот, потеря фокуса и смена полноэкранного режима также ставят забег на паузу.

Если браузер не разрешает настоящий полный экран, игра разворачивается на доступное окно. Панели самого браузера в таком режиме могут оставаться видимыми. Повторное нажатие ⛶ / F закрывает этот режим; Esc также закрывает разворачивание на окно.

## Правила и разгон

- Три огонька здоровья. Столкновение с банкой отнимает один; после столкновения действует краткая неуязвимость.
- Примогем добавляет 25 метров к результату.
- Скорость: ×1 при старте, ×2 к 3:00, ×5 к 10:00, ×13 к 30:00 активного забега. Паузы не учитываются.
- Темп анимации бега котика, прыжок, расположение и типы банок, расстояния между ними и маски столкновений сохранены из v43.
- Рекорд сохраняется локально в браузере. При запрете локального хранилища игра продолжает работать, но сохранение между посещениями недоступно.

## Файлы и изменения

- `game.js` — физика, препятствия, счёт, звук и отрисовка.
- `features.js` — обучение, диалоги, поворот и полноэкранный режим.
- `animation-config.js` — параметры рисунков и анимации.
- `collision-masks.js` — подготовленные маски столкновений.
- `style.css` — единые стили и адаптивные раскладки.
- `assets/` — изображения, сжатые без потерь. Все 11 растровых изображений после декодирования побитно совпадают по RGBA с исходными.
- `AUDIT.md` — подробные результаты проверки и её ограничения.
- `tests/validation-results.json` — сводные результаты.
- `tests/game-regression.mjs` — автономный тест таймера, генерации, одиночных прыжков и масок. Запуск из папки проекта: `node tests/game-regression.mjs` (Node.js 20+). Для самой игры Node.js не нужен.

Сборка ориентирована на актуальные браузеры. В проверке использовались Chromium, Firefox и WebKit, включая эмуляцию сенсорного ввода. Проверка движка WebKit не заменяет запуск на физическом iPhone: системные панели, вырез экрана и разрешение на блокировку ориентации зависят от устройства и браузера.
